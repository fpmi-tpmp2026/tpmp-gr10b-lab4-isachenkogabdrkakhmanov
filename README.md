# Project Name

**Автопарк** — консольное приложение для учета автомобилей, водителей и заказов на перевозку грузов.

## Description

Приложение предназначено для хранения и обработки данных об автомобилях автопарка, водителях и выполненных заказах на перевозку грузов.  
Система поддерживает аутентификацию и авторизацию пользователей, просмотр информации по автомобилям, водителям и заказам, а также выполнение запросов, предусмотренных вариантом задания.  

## Installation

### Требования

Для локального запуска проекта необходимо установить:

- Git
- Компилятор C
- CMake или Make
- SQLite3
- Git Bash / Terminal 

### Шаги установки

1. Клонировать репозиторий:
   ```bash
   git clone <https://github.com/CYBERT00AD/lab4-tpmp.git>
   ```

2. Перейти в папку проекта:
   ```bash
   cd <lab4-tpmp>
   ```

3. Создать директорию сборки:
   ```bash
   mkdir build
   ```

4. Собрать проект.

   Вариант через CMake:
   ```bash
   cmake -S . -B build
   cmake --build build
   ```

   Вариант через Makefile:
   ```bash
   make
   ```
